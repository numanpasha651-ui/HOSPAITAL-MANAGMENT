XYZ HOSPITAL - Hospital Management Website
==========================================
1. Install Python 3 (python.org) if you don't have it.
2. Open this folder in a terminal / command prompt.
3. Run:   python app.py
4. Open:  http://localhost:8000

No extra packages needed. Data is saved in hospital.db (created automatically
with 3 sample patients). Delete hospital.db to reset everything.
To change room rates, edit ROOM_RATES at the top of app.py.
